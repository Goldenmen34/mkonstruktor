## ⚡ Быстрый старт (Краткая шпаргалка для владельца)

### 👑 1. Включить PRO для себя без ключей:
- Нажмите в конструкторе **`Ctrl + Shift + K`** (или золотую кнопку с короной **«Ключи»** в правом верхнем углу).
- Откройте вкладку **«👑 Для себя»** -> нажмите зеленую кнопку **«Активировать Бессрочный VIP»**.

### 💼 2. Выдать ключ клиенту:
- В генераторе введите имя клиента (или фабрики), выберите тариф (например, *All-Inclusive*) и срок (например, *1 год / 365 дней*).
- Нажмите **«Сгенерировать ключ»**.
- Нажмите кнопку **«Скопировать сообщение клиенту»** и отправьте текст в Telegram или WhatsApp.

### 🔑 3. Мастер-ключи для ручного ввода:
- `BPL-PRO-LIFETIME` — Бессрочный All-Inclusive VIP
- `BPL-VIP-2026` — All-Inclusive на 1 год
- `BPL-KITCHEN-PRO` — Кухни PRO на 90 дней
