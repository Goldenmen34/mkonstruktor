# МКонструктор 3D — Мебельный Конструктор и SaaS-Платформа

Полнофункциональный веб-конструктор корпусной мебели на базе **Three.js** и **React**. Разработан как независимая, быстрая и защищённая альтернатива дорогостоящим зарубежным САПР.

---

## 🚀 Возможности системы

### 1. 3D-Ядро и Графика (Three.js)
* **PBR-материалы:** Реалистичный глянец, матовые soft-touch покрытия, текстуры дерева (Дуб Вотан/Сонома), мрамор, камень, графит и металл.
* **Режимы отображения:**
  * Полноценная 3D-перспектива с мягкими тенями.
  * Вид спереди (прямая проекция).
  * 2D-план помещения (ортогональный вид сверху).
* **Интерактивность:** Плавная анимация открывания фасадов и выдвижения ящиков по клику одной кнопки.
* **Магнитная привязка (Snapping):** 
  * Автоматическое прилипание шкафов задней стенкой к стенам комнаты.
  * Автоматическая стыковка шкафов «бок о бок» вдоль стены.

### 2. Модульность: Кухни и Шкафы
* **Модуль «Кухни»:**
  * Напольные базы (1 дверь, 2 двери, 3 выдвижных ящика, под мойку, под встраиваемую духовку, угловые секции).
  * Навесные шкафы (распашные, горизонтальные антресоли с подъемниками).
  * Пеналы и колонны (под холодильник, под духовку и СВЧ).
  * Автоматическая столешница и цоколь.
* **Модуль «Шкафы»:**
  * Шкафы-купе (2-х и 3-х дверные системы).
  * Распашные шкафы для спален и прихожих с полками и ящиками.

### 3. Параметризация (в миллиметрах)
* Изменение ширины, высоты и глубины любого модуля в реальном времени ползунками или полями ввода.
* Поворот модулей на 90°, дублирование и удаление.
* Изменение размеров и отделки помещения.

### 4. Коммерческая смета и Экспорт в PDF
* Динамический подсчёт стоимости мебели в реальном времени с учётом габаритов.
* Автоматический расчёт столешниц, фурнитуры и сборки (10%).
* **Генерация брендированного PDF-коммерческого предложения в 1 клик:**
  * Фотореалистичный 3D-снимок текущего проекта.
  * Таблица спецификации с артикулами и размерами в мм.
  * Итоговая сумма к оплате.

### 5. Система SaaS-подписок и лицензионных ключей
* **Демо-режим:** Ограничение до 8 секций на сцене. При превышении открывается окно активации.
* **Мастер-ключи для демонстрации:**
  * `BPL-VIP-2026` — Премиум лицензия на 1 год (Кухни + Шкафы, без ограничений).
  * `BPL-KITCHEN-PRO` — Лицензия на 90 дней (Модуль «Кухни»).
  * `BPL-WARDROBE-PRO` — Лицензия на 90 дней (Модуль «Шкафы»).
  * Любой ключ формата `BPL-XXXX-YYYY-ZZZZ` — автоматическая подписка на 30 дней.
* Экспорт и сохранение всего проекта в `.json` и загрузка обратно в конструктор.

## 💻 Быстрый запуск

1. Запустите двойным кликом файл **`start.bat`**  
   или в терминале выполните:
   ```bash
   npm run dev
   ```
2. Откройте в браузере: **`http://localhost:3000`**

---

## 📦 Сборка для сервера (Production)

Для развертывания на любом хостинге или VPS:
```bash
npm run build
```
Готовая статическая сборка появится в папке `dist/`. Её можно загрузить на любой веб-сервер (Nginx, Apache) или бесплатно на Cloudflare Pages / Vercel.
