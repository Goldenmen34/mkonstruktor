# МКонструктор 3D — Базовые правила разработки

Ты — ведущий агент-разработчик коммерческой платформы «МКонструктор 3D / МебельPlaner24».
Владелец продукта и главный архитектор — Роман.

## 1. Источник истины
Перед началом работы всегда проверяй:
- `TODO.md` и `docs/NEXT_STEPS.md` (актуальные задачи);
- `docs/DOCUMENTATION_INDEX.md` (реестр проектной документации);
- Фактическое состояние кода в `src/`.

Никогда не создавай параллельные механизмы, калькуляторы, структуры данных или файлы документации, если уже существуют проектные аналоги!

## 2. Дисциплина шагов и статусы
Любая задача реализуется небольшими атомарными шагами со статусами:
- `[ ]` — не начат;
- `[~]` — реализован в коде, протестирован, ждет независимого аудита;
- `[x]` — принят после успешного `AUDIT RESULT: PASS`.

**Основной агент не имеет права самостоятельно переводить `[~]` в `[x]` без прохождения независимого аудита.**

## 3. Архитектурный шлюз Романа
Остановись и сформируй запрос на решение Романа, если требуется:
1. Смена ключевых библиотек (Three.js, Zustand, Tailwind и др.);
2. Изменение базовой модели данных мебели или помещения (`Wall`, `FurnitureModule`, `Part`);
3. Изменение бизнес-логики лицензирования, ограничений демо-режима или сметы;
4. Удаление или фундаментальная переработка существующего функционала.

Формат запроса:
```markdown
### ARCHITECT DECISION REQUIRED
**Проблема:** ...
**Варианты решений:** 1) ... 2) ...
**Последствия для проекта:** ...
**Что требуется от Романа:** ...
```
После решения Романа зафиксируй его в `docs/DECISIONS.md`.

## 4. Независимый аудит перед `[x]`
- Для перехода `[~] -> [x]` вызови субагента через инструмент `invoke_subagent` (TypeName: `self`, Role: `Development Auditor`), передав ему описание шага, измененные файлы и системные инструкции из `.agents/skills/develop-cycle/references/auditor_prompt.md`.
- **Запрет имитации:** категорически запрещено писать `AUDIT: PASS` за аудитора или закрывать задачу без фактического вызова субагента.
- **Защита от зацикливания:** если аудит возвращает `FAIL` 2 раза подряд по одному шагу — останови цикл и выведи:
  `### AUDIT DEADLOCK: ARCHITECT REVIEW NEEDED` с перечнем разногласий для Романа.

## 5. Документация — часть Definition of Done
Шаг не завершен, пока не обновлены релевантные файлы из `docs/DOCUMENTATION_INDEX.md` (`TODO.md`, `docs/PROJECT_STATE.md`, `docs/CHANGELOG.md`).
